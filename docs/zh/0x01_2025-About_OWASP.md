# 关于 OWASP

开放全球应用程序安全项目（OWASP, Open Worldwide Application Security Project）是一个开放的社区，致力于使组织能够开发、采购和维护可信赖的应用程序和 API。

在 OWASP，您可以找到免费和开放的：

- 应用程序安全工具和标准
- 前沿研究
- 标准安全控制措施和库
- 关于应用程序安全测试、安全代码开发和安全代码审查的完整书籍
- 演示文稿和 [视频](https://www.youtube.com/user/OWASPGLOBAL)
- 关于许多常见主题的 [速查表](https://cheatsheetseries.owasp.org/)
- 在全球和线上举行的 [分会会议](https://owasp.org/chapters/)
- [活动、培训和会议](https://owasp.org/events/)
- [Google 群组](https://groups.google.com/g/owasp)

了解更多：[https://owasp.org](https://owasp.org)。

所有 OWASP 工具、文档、视频、演示文稿和分会都对任何有兴趣改进应用程序安全的人免费开放。

我们倡导将应用程序安全作为人员、流程和技术问题来对待，因为最有效的应用程序安全方法需要在所有这些领域进行改进。

OWASP 是一个与众不同的组织。我们不受商业压力的影响，这使我们能够提供关于应用程序安全的无偏见、实用且经济高效的信息。

OWASP 不隶属于任何技术公司，尽管我们支持商业安全技术的知情使用。OWASP 以协作、透明和开放的方式制作多种类型的材料。

OWASP 基金会是一个非营利实体，确保项目的长期成功。几乎所有与 OWASP 相关的人都是志愿者，包括 OWASP 董事会、分会负责人、项目负责人和项目成员。我们通过资助和基础设施支持创新的安全研究。
