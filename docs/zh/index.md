# OWASP Top 10:2025

欢迎使用 OWASP Top 10:2025 版本。

OWASP Top 10 是面向开发人员和 Web 应用程序安全的标准认知文档。它代表了关于 Web 应用程序最关键安全风险的广泛共识。

## 关于本版本

这是 OWASP Top 10 的 **2025** 版本。本版本包含了基于最新数据和安全趋势的更新。
