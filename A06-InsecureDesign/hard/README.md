# 笔记应用 (Hard)

## 题目描述

这是一个简洁的笔记应用。你可以查看自己的笔记，也支持批量查询。据说管理员藏了一份机密笔记，你能找到它吗？

## 题目信息

- **分类**：A06 Insecure Design
- **难度**：Hard
- **端口**：80

## 访问方式

访问 `http://<target>:80` 查看笔记列表。

## API说明

| 接口 | 方法 | 描述 |
|------|------|------|
| `/api/my-notes` | GET | 获取当前用户的笔记列表 |
| `/api/note/<id>` | GET | 单条查询笔记（有权限校验） |
| `/api/notes/batch` | POST | 批量查询笔记，请求体 `{"ids": [1, 2, 3]}` |
