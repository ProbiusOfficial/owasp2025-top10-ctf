# A01 Broken Access Control - Hard

## 题目信息
- **难度**: Hard
- **类型**: Web / SSRF（服务器端请求伪造）
- **考点**: A01 - 失效的访问控制（SSRF内网探测与绕过）

## 题目描述

这是一个在线图片获取服务，用户可以提交图片URL，服务器会代为获取图片内容并展示。

出于安全考虑，系统禁止访问内网地址（如 `127.0.0.1`、`localhost` 等）。

## 题目目标

利用 SSRF 漏洞访问内网的 flag 服务，获取 flag。

## 访问方式

```
http://<target>:80/
```

## 提示

- 系统存在 SSRF 漏洞
- 基本的黑名单过滤可能可以被绕过
- 内网有一个 flag 服务在运行
- 127.0.0.1 有很多等价表示方式
