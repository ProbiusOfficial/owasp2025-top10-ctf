# A01 Broken Access Control - Medium

## 题目信息
- **难度**: Medium
- **类型**: Web / JWT 权限绕过
- **考点**: A01 - 失效的访问控制（前端权限控制绕过）

## 题目描述

这是一个"安全"的文档管理平台，使用了 JWT 进行身份认证。

平台有两个角色：
- `user` - 普通用户
- `admin` - 管理员

登录后，前端会根据 JWT 中的 `role` 字段决定是否显示管理员功能。普通用户登录后看不到管理员面板。

## 题目目标

以普通用户身份登录，想办法获取管理员接口中的 flag。

